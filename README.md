# Pilotage scolaire CSSPS — Tableau de bord

**Date de création** : 2026-04-11
**Statut** : En démarrage

## Objectif

Dashboard interactif de pilotage scolaire pour le CSSPS, alimenté par les données ouvertes du MEES (Ministère de l'Éducation et de l'Enseignement supérieur du Québec). Permet de visualiser et suivre les indicateurs clés de performance scolaire.

## Stack technique

- **Frontend** : React + Vite + Tailwind CSS
- **Déploiement** : Netlify
- **Données** : Données ouvertes MEES

## Structure du projet

```
pilotage-scolaire-cssps-20260411/
├── data/          # Données brutes et traitées (CSV, JSON)
├── src/           # Code source React
├── outputs/       # Exports, rapports, captures
└── README.md
```
